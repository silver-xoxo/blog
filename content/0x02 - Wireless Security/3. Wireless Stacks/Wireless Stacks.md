Linux Supports Two Wireless Stacks :

- ieee80211 framework
- mac80211 framework

##### IEEE80211 Framework :

This Wireless extension in Linux took part in three Parts :

1. Set of User tools to control the drivers
2. Implemented wext \[wireless extension] in Wi-Fi Drivers to answer actions triggered by tools.
3. kernel
